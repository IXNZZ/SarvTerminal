Sarv Terminal 1.10.3

Improvements & fixes

Release

  • sign the app with its entitlements so shipped builds stop losing them

Build

  • keep com.sarv.terminal on ReleaseLocal, which is the configuration that ships
  • give ReleaseLocal its own bundle id so it can't revoke the shipping app's permissions

SSH

  • poll a connected session every 2s instead of 0.2s so tabs stop flooding the main run loop
  • detect a dropped session from the core process state so background tabs auto-reconnect

Queue

  • wake the consumer before a bounded push can block so the app can't deadlock
